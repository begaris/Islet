Islet nustatymų gidas

Kaip įjungti orus, valiutas, AI pokalbį ir balsą į tekstą. Visi nustatymai yra programoje: salos skydelyje paspauskite slankiklių ikoną (dešinėje viršuje) ir slinkite iki Network. Pakeitimai įsigalioja iškart.

Kas veikia be jokio rakto

  • Orai: nemokama, be paskyros. Tik įjunkite ir įrašykite miestą.
  • Valiutų skaičiuoklė: nemokama, be paskyros (Europos centrinio banko kursai).
  • Balsas į tekstą „On this PC“: nemokama, veikia be interneto (tik anglų kalba).
  • AI pokalbis per „Claude login“ arba „ChatGPT login“: naudoja jūsų esamą Claude ar ChatGPT prenumeratą, papildomai nieko nemokate. Reikia tik vieną kartą prisijungti.

AI pokalbis (Chat skirtukas)

Pirmiausia Settings › Network › AI chat įjunkite. Tada pasirinkite Chat provider: vieną iš būdų žemiau.

A. Claude login: jūsų Claude paskyra Rekomenduojama

Tinka, jei kompiuteryje yra Claude programa ir turite Claude Pro arba Max planą. Islet naudoja kartu su Claude programa įdiegtą Claude Code, todėl API rakto nereikia.

  1. Chat provider pasirinkite Claude login.
  2. Eilutėje Claude login paspauskite Sign in. Atsidarys juodas langas ir naršyklė.
  3. Naršyklėje prisijunkite savo Claude paskyra ir patvirtinkite (Authorize).
  4. Grįžkite į Islet: po kelių sekundžių eilutėje atsiras Signed in ✓. Juodą langą galite uždaryti.
  5. Atidarykite Chat skirtuką ir rašykite.

Ką verta žinoti:

  • Atsakymai skaičiuojami į jūsų Claude plano limitus (tie patys, kaip naudojant Claude programą).
  • Pirmas žodis pasirodo po maždaug 2–4 sekundžių: kiekvienam atsakymui fone paleidžiamas Claude Code.
  • Claude čia tik kalbasi: jis negali nieko daryti jūsų kompiuteryje (visi įrankiai išjungti).
  • PDF, Word, Excel ir tekstinių failų turinį siųsti galima. Paveikslėlių šiuo būdu siųsti nepavyks: jiems reikia B arba C būdo.
  • Modelį galima pasirinkti lauke Chat model (pvz. sonnet arba opus). Tuščias laukas reiškia jūsų plano numatytąjį modelį.

Jei rodo „Claude app not found“, įdiekite Claude programą iš claude.ai/download.

A2. ChatGPT login: jūsų ChatGPT paskyra Be rakto

Tas pats principas, tik su OpenAI: tinka, jei kompiuteryje yra Codex programa (OpenAI) ir turite ChatGPT planą (Plus, Pro ir pan.). Islet naudoja jos įdiegtą Codex.

  1. Chat provider pasirinkite ChatGPT login.
  2. Eilutėje ChatGPT login paspauskite Sign in ir prisijunkite naršyklėje savo ChatGPT paskyra (jei Codex programoje jau esate prisijungę, matysite Signed in ✓ iškart).
  3. Atidarykite Chat skirtuką ir rašykite.
  • Atsakymai skaičiuojami į jūsų ChatGPT plano limitus.
  • Atsakymas pasirodo visas iš karto (ne po žodį), maždaug po 5–10 sekundžių.
  • Paveikslėlius siųsti galima.
  • Codex veikia tik skaitymo režimu ir yra paprašytas nieko nedaryti kompiuteryje, tik atsakyti.
  • Jei Codex programos neturite, ją rasite OpenAI svetainėje (ieškokite „Codex app“).

Modelio pasirinkimas

  • Settings › Network › Model: rodyklėmis ‹ › perjunkite modelius. Sąrašas priklauso nuo tiekėjo: Claude login: Opus / Sonnet / Haiku; ChatGPT login: modeliai iš jūsų Codex; Anthropic API: Opus 5.5 / Sonnet 5.5 / Haiku 5.5; OpenAI-compatible: sąrašas gaunamas iš paties serverio.
  • Greičiau: Chat skirtuko viršuje kairėje paspauskite modelio pavadinimą (pvz. „Claude · Sonnet ›“), ir bus parinktas kitas modelis.
  • Modelio, kurio sąraše nėra, pavadinimą galite įrašyti į Other model.

Pokalbiai Claude Code ir Codex programose

Naudojant Claude login arba ChatGPT login, kiekvienas Islet pokalbis išsaugomas ir pačiame Claude Code / Codex (aplanke C:\Users\<jūs>\Islet Chat). Todėl:

  • Claude / ChatGPT tikrai prisimena visą pokalbį, o ne jo santrauką.
  • Chat skirtuko viršuje dešinėje atsiranda mygtukas Open in Claude Code (arba Open in Codex). Jis atidaro tą patį pokalbį atskirame lange: jį matote ir galite tęsti ten.
  • Pokalbį taip pat rasite paleidę claude --resume (arba codex resume) aplanke „Islet Chat“. Claude pavadina jį „Islet: …“ pagal pirmus žodžius.
  • + mygtukas Chat skirtuke pradeda naują pokalbį (senasis lieka Claude Code / Codex istorijoje).

Į įprastą claude.ai ar chatgpt.com pokalbių sąrašą (ir Claude programos šoninę juostą) kitos programos pokalbių įrašyti negali. Patikrinau: šios istorijos niekas išorėje papildyti neleidžia. Todėl pokalbis atidaromas Claude Code / Codex lange.

B. Anthropic API raktas Mokama pagal naudojimą

Atskira paslauga programuotojams: mokate už kiekvieną atsakymą, nepriklausomai nuo Claude Pro prenumeratos (tai dvi skirtingos sąskaitos).

  1. Eikite į console.anthropic.com ir susikurkite paskyrą (galite prisijungti tuo pačiu el. paštu).
  2. Settings › Billing: įneškite kreditą (pakanka kelių dolerių; trumpas pokalbis kainuoja centų dalis).
  3. Settings › API keys › Create key: duokite pavadinimą (pvz. „Islet“) ir nukopijuokite raktą (prasideda sk-ant-). Jis rodomas tik vieną kartą.
  4. Islet: Chat provider pasirinkite Anthropic API.
  5. Atidarykite Chat skirtuką, paspauskite įvesties lauką, įklijuokite raktą (Ctrl+V) ir spauskite Enter. Raktas saugomas užšifruotas, tik jūsų Windows vartotojui.
  • Chat model tuščias reiškia numatytąjį claude-opus-5-5. Pigiau ir greičiau: claude-sonnet-5-5 arba claude-haiku-5-5.
  • Raktą pakeisti: Chat lauke parašykite /key ir Enter, tada įklijuokite naują.
  • Jei raktas jau įrašytas sistemoje kaip ANTHROPIC_API_KEY, Islet jį pasiims pats (žr. Raktai sistemoje).

C. OpenAI arba OpenRouter Mokama pagal naudojimą

  1. OpenAI: platform.openai.com/api-keys, tada Create new secret key (prasideda sk-). Kreditą įneškite Billing skiltyje.
    OpenRouter (daug skirtingų modelių su vienu raktu): openrouter.ai/keys.
  2. Islet: Chat provider pasirinkite OpenAI-compatible.
  3. OpenAI-compatible address:
    • OpenAI: https://api.openai.com/v1
    • OpenRouter: https://openrouter.ai/api/v1
  4. Chat model būtinas: įrašykite modelio pavadinimą tiksliai taip, kaip jis parašytas paslaugos modelių sąraše (OpenAI modeliai, OpenRouter modeliai).
  5. Chat skirtuke įklijuokite raktą ir spauskite Enter (arba naudokite OPENAI_API_KEY).

D. Nemokamas modelis jūsų kompiuteryje Nemokama, be interneto

Jei turite galingą vaizdo plokštę, modelį galite paleisti pas save. Tada niekas neišeina iš kompiuterio. Atsakymų kokybė priklauso nuo modelio dydžio.

  1. Įdiekite Ollama arba LM Studio.
  2. Atsisiųskite modelį (Ollama: komandų eilutėje ollama pull <modelio-pavadinimas>; pavadinimus rasite ollama.com/library. LM Studio tą patį leidžia padaryti programos lange).
  3. Islet: Chat provider OpenAI-compatible, adresas:
    • Ollama: http://localhost:11434/v1
    • LM Studio: http://localhost:1234/v1 (įjunkite jo Local Server)
  4. Chat model: tas pats pavadinimas, kurį atsisiuntėte.
  5. Chat skirtukas paprašys rakto: įrašykite bet ką (pvz. local). Vietiniams serveriams raktas nereikalingas.

Balsas į tekstą

Paspauskite Alt+Shift+D (kombinaciją galima pakeisti Settings › Shortcuts), kalbėkite, ir tekstas bus įrašytas ten, kur mirksi žymeklis. Dar kartą paspaudus įrašymas baigiamas.

PasirinkimasKaip veikiaKo reikia
On this PCWindows kalbos atpažinimas, be interneto, nemokamai.Nieko. Šiame kompiuteryje veikia tik anglų kalba.
OnlineĮrašas siunčiamas transkribavimo paslaugai. Supranta ir lietuviškai.OpenAI raktas (C būdas) arba OPENAI_API_KEY.

Lietuvių kalbai „Online“ režime Voice language (online) įrašykite lt (tuščias laukas: kalbą atpažįsta pats). Numatytoji paslauga: OpenAI, modelis whisper-1 (keičiama nustatymų faile: voice_url, voice_model).

Jei pokalbiui naudojate Claude login arba Anthropic API, balsui „Online“ vis tiek reikia OpenAI rakto: Anthropic kalbos atpažinimo paslaugos neturi. Lengviausia jį įrašyti kaip OPENAI_API_KEY (kaip).

Orai

  1. Settings › Network › Weather: įjunkite.
  2. City: įrašykite miestą (pvz. Vilnius, Kaunas) ir spauskite Enter.
  3. Po kelių sekundžių temperatūra atsiras saloje, o prognozė – Weather skirtuke. Atnaujinama kas 30 minučių.

Duomenys iš open-meteo.com: nemokamai, be paskyros.

Valiutų skaičiuoklė

  1. Settings › Network › Currency conversion: įjunkite.
  2. Your currency: jūsų valiuta (pvz. EUR).
  3. Atidarykite komandų juostą (Alt+Space) ir rašykite, pvz.: 100 usd to eur, 50 £, 20 eurų į dolerius, 1,5k pounds. Enter nukopijuoja rezultatą.

Kursai iš Europos centrinio banko (per frankfurter.dev), atnaujinami kartą per dieną.

Raktai sistemoje (aplinkos kintamieji)

Jei API raktą įrašysite į Windows, Islet (ir kitos programos) jį ras pačios. Tada jo nereikia klijuoti Chat skirtuke.

  1. Paspauskite Win, įrašykite „environment variables“ ir pasirinkite Edit environment variables for your account (lietuviškoje Windows: Redaguoti savo paskyros aplinkos kintamuosius).
  2. Viršutinėje dalyje spauskite New…
  3. Pavadinimas: ANTHROPIC_API_KEY arba OPENAI_API_KEY. Reikšmė: jūsų raktas. Spauskite OK.
  4. Išjunkite Islet (dėklo ikona › Quit) ir vėl paleiskite: naujus kintamuosius programa mato tik paleista iš naujo.

Raktas, įklijuotas Chat skirtuke, turi pirmenybę prieš kintamąjį.

Atnaujinimų tikrinimas

Kol Islet niekur nepaskelbtas, šis nustatymas nieko neras: palikite išjungtą. Kai turėsite GitHub saugyklą su leidimais, įrašykite https://api.github.com/repos/<vartotojas>/<saugykla>/releases/latest ir įjunkite. Islet kartą per dieną praneš apie naują versiją, bet pats nieko nesiųs.
